# Правила работы над этим проектом

## Коммиты

Коммить автоматически, не дожидаясь отдельной просьбы.

- После каждого завершённого смыслового изменения делать коммит — не копить
  правки до конца сессии.
- Разбивать по смыслу: разметка, стили, документация и архив — отдельные коммиты.
- Сообщения в стиле Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`,
  `refactor:`), тело — на английском.
- `git push` — только по явной просьбе.

## Проект

Статический одностраничный сайт-визитка столярной мастерской «נגריית אלון».
Только HTML + CSS: без фреймворков, без npm, без сборки, без JavaScript.
Мобильное меню сделано на `<details>`/`<summary>`, чтобы не тянуть JS.

Язык интерфейса — иврит, направление RTL (`<html lang="he" dir="rtl">`).

- `index.html` — вся структура и текст, включая политику приватности
- `style.css` — всё оформление
- `previous-version/` — архив предыдущей версии с локальными картинками, не трогать
- `pics/` — исходники изображений, в git не попадают (см. `.gitignore`)

Все изображения на сайте грузятся с Cloudinary (cloud `zrevzjvb`, папка
`nagar-alon-pics`). Соответствие `public_id` → URL описано в `cloudinary-assets.md`.
Новые картинки добавлять туда же, локальные пути в `index.html` не использовать.
