# images/

כל התמונות באתר הן **הדמיות** להמחשת סגנון וסוגי עבודות — לא צילומים מפרויקטים שבוצעו.

## מוסכמת שמות

| בסיס | תפקיד | יחס | רוחבים בקובץ |
|---|---|---|---|
| `hero-*` | תמונת פתיחה | 3:2 | 560 / 840 / 1120 |
| `gallery-01` … `gallery-10` | גלריית עבודות | 4:5 | 400 / 800 |

לכל רוחב נדרשים שלושה קבצים: `.avif`, `.webp`, `.jpg`
(לדוגמה: `gallery-01-400.avif`, `gallery-01-400.webp`, `gallery-01-400.jpg`).

## מצב נוכחי

קיימים: `hero`, `gallery-03`, `gallery-04`, `gallery-06`, `gallery-08`, `gallery-10`.

חסרים ויש לייצר: `gallery-01`, `gallery-02`, `gallery-05`, `gallery-07`, `gallery-09`
(שולחן אוכל, שולחן אוכל, מזנון, ספרייה, קיר אחסון).

## החלפת תמונה

לשמור על אותו יחס גובה-רוחב (4:5 לגלריה, 3:2 ל-hero), לייצר את שלושת הפורמטים
בשני הרוחבים, ולשמור על אותם שמות קבצים. אין צורך לשנות את `index.html`.
