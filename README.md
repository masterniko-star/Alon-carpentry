# נגריית אלון — אתר תדמית סטטי

אתר עמוד אחד, HTML + CSS בלבד. ללא framework, ללא ספריות, ללא npm, ללא שלב build
וללא JavaScript. כל התמונות נטענות מ-Cloudinary (cloud `zrevzjvb`, תיקייה `nagar-alon-pics`).

## קבצים

```
index.html            כל מבנה האתר והתוכן (כולל מדיניות הפרטיות)
style.css             כל העיצוב
toda.html             עמוד מצב אחרי שליחת טופס מוצלחת
shgia.html            עמוד מצב אחרי שליחה שנכשלה
cloudinary-assets.md  מיפוי התמונות ב-Cloudinary וכללי האספקה שלהן
README.md             הקובץ הזה
```

אין `script.js` — לא נדרש JavaScript לשום פונקציה באתר.
תפריט הנייד מבוסס על `<details>`/`<summary>` של HTML, ולכן נגיש למקלדת כברירת מחדל.

## שפת העיצוב

העמוד בנוי כדף שרטוט של נגרייה. כל החלטה חזותית נגזרה מהסדנה עצמה, לא מגווני
"עץ חמים" — החום היחיד בעמוד הוא התמונות, והרקע הקר גורם להן להיקרא כפריטים
על שולחן עבודה.

**צבעים** (מוגדרים כמשתנים בראש `style.css`):

| משתנה | ערך | מקור |
|---|---|---|
| `--shop` | `#E8E9E4` | קיר סדנה מסויד באור צפוני — רקע העמוד |
| `--sheet` | `#F4F4F1` | דף תוכנית חיתוך ולוח מנוסר טרי — משטחי תוכן |
| `--pencil` | `#1B1D1C` | גרפיט של עיפרון נגרים — טקסט ו-footer |
| `--pencil-soft` | `#4C514E` | אותו עיפרון בלחיצה קלה — טקסט משני |
| `--petrol` | `#1A3639` | צבע המפעל של מכונות נגרות — כותרות, כפתורים, הפס הכהה |
| `--tape` | `#E0A21A` | להב סרט מדידה — **סימון בלבד**, לעולם לא טקסט על רקע בהיר |

**טיפוגרפיה** — שלושה תפקידים, כולם מגופני המערכת (אין פונטים חיצוניים):
תצוגה במשקל 700 עם ריווח אותיות שלילי (`h1`, `h2`), גוף במשקל 400, ותפקיד
"הערת שרטוט" (`--font-note`, רוחב אות קבוע וריווח 0.14em) לכל מה שהוא נתון —
תוויות, מספרי שלבים, ערכי מידה וכיתובי הגלריה.

**קו המידה** הוא האלמנט המזהה: שתי צלעות עם ראשי חץ וקווי הארכה, וביניהן ערך.
מתחת לתמונת ה-hero הערך אינו מספר אלא `X`, כי המידה שייכת ללקוח ועוד לא נמדדה.
אותה שפה חוזרת בסעיף תהליך העבודה, שם הקו נהיה סרגל והמספרים יושבים עליו.

**כללי משמעת** לכל שינוי עתידי: רדיוס אחד בלבד (`--r-break`, שני פיקסלים),
בלי מרקמי רקע — מרקם שאינו נראה על המסך פשוט יוסר, ובלי אלמנט "מיוחד" נוסף:
קו המידה הוא הרעש היחיד המותר בעמוד.

## איך לפתוח

לחיצה כפולה על `index.html` פותחת את האתר בדפדפן. אין צורך בשרת.
(דרוש חיבור אינטרנט כדי שהתמונות והלוגו ייטענו מ-Cloudinary.)

להרצה משרת מקומי, אם מעדיפים:

```
python -m http.server 8000
```

ואז לגשת ל-`http://localhost:8000`.

## איך לפרסם

להעלות את שלושת הקבצים לשורש של כל אחסון סטטי — Netlify, Cloudflare Pages,
GitHub Pages, Vercel או שרת Nginx/Apache רגיל. אין תלויות ואין תהליך build.


## איך להחליף תמונה

כל כתובת תמונה בנויה כך:

```
https://res.cloudinary.com/zrevzjvb/image/upload/<טרנספורמציות>/<גרסה>/nagar-alon-pics/<שם הקובץ>.png
```

לדוגמה:

```
.../upload/f_avif,q_auto:eco,c_fill,g_auto,ar_4:5,w_800/v1787857693/nagar-alon-pics/pic_alon_1.png
```

* `f_avif` / `f_auto` — פורמט התמונה. **לא למחוק.**
* `q_auto:eco` — דחיסה אוטומטית בדרגה חסכונית. **לא למחוק.**
* `c_fill,g_auto` — חיתוך חכם שממורכז על נושא התמונה.
* `ar_4:5` — יחס גובה-רוחב (גלריה 4:5, hero 3:2).
* `w_400` … `w_800` — הרוחבים שמופיעים ב-`srcset`.
* `v1787857693` — מספר גרסת הנכס ב-Cloudinary.

כל תמונת תוכן עטופה ב-`<picture>` עם שני מקורות:

* `<source type="image/avif">` עם `f_avif` — מה שרוב הטלפונים מקבלים בפועל.
* `<img>` עם `f_auto` — גיבוי לדפדפנים בלי AVIF (מקבלים WebP, ובמקרה קיצון JPEG).

הסיבה ל-`f_avif` מפורש: בחשבון Cloudinary הזה `f_auto` מגיש WebP ולא AVIF, ו-AVIF
קטן ממנו בכ-45% באותה איכות. אם AVIF יופעל בהגדרות החשבון, אפשר יהיה להסיר את
ה-`<source>` ולהסתפק ב-`f_auto`.

להחלפת תמונה: להעלות קובץ חדש לתיקייה `nagar-alon-pics`, ואז להחליף בקוד רק את
**שם הקובץ ואת מספר הגרסה** — ולהשאיר את הטרנספורמציות כפי שהן. חשוב לעדכן את כל
הופעות אותה תמונה באלמנט (`src` ושני ה-`srcset`), ואת ה-`alt` לתיאור מה שנראה
בתמונה החדשה.

אם התמונה החדשה אינה ביחס 4:5 או 3:2, ה-`c_fill,g_auto` יחתוך אותה לפי היחס
המבוקש — לכן כדאי לבדוק שהחיתוך לא פוגע ברהיט.

## נגישות וביצועים

* `lang="he"`, `dir="rtl"`, פריסה מבוססת logical properties.
* קישור דילוג לתוכן, מבנה כותרות תקין (h1 יחיד), landmarks סמנטיים.
* `<label>` אמיתי לכל שדה, `aria-describedby` לטקסטי עזר, מצבי focus ברורים.
* כל התמונות עם `alt` בעברית, `width`/`height` מפורשים ו-`decoding="async"`.
* תמונת ה-hero נטענת ב-`fetchpriority="high"` וללא `loading="lazy"`; כל היתר `lazy`.
* `srcset` + `sizes` לכל תמונה משמעותית, ברוחבים מכוילים למסכי טלפון ב-DPR 2–3.
* `<picture>` עם `<source type="image/avif">` לכל תמונת תוכן, ו-`q_auto:eco` בכל
  כתובת Cloudinary — יחד כ-51% פחות בייטים בטעינה מטלפון.
* `preconnect` ל-`res.cloudinary.com` ו-`preload` לתמונת ה-hero (ה-LCP).
* `prefers-reduced-motion` מבטל גלילה חלקה ומעברים.
* ללא פונטים חיצוניים, ללא trackers, ללא cookies.
