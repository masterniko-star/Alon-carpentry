# נגריית אלון — אתר תדמית סטטי

אתר עמוד אחד, HTML + CSS בלבד. ללא framework, ללא ספריות, ללא npm, ללא שלב build
וללא JavaScript. כל התמונות נטענות מ-Cloudinary (cloud `zrevzjvb`, תיקייה `nagar-alon-pics`).

## קבצים

```
index.html    כל מבנה האתר והתוכן (כולל מדיניות הפרטיות)
style.css     כל העיצוב
README.md     הקובץ הזה
```

אין `script.js` — לא נדרש JavaScript לשום פונקציה באתר.
תפריט הנייד מבוסס על `<details>`/`<summary>` של HTML, ולכן נגיש למקלדת כברירת מחדל.

## איך לפתוח

לחיצה כפולה על `index.html` פותחת את האתר בדפדפן. אין צורך בשרת.
(דרוש חיבור אינטרנט כדי שהתמונות והלוגו ייטענו מ-Cloudinary.)

להרצה משרת מקומי, אם מעדיפים:

```
python -m http.server 8000
```

ואז לגשת ל-`http://localhost:8000`.

## איך לפרסם

להעלות את שלושת הקבצים לשורש של כל אחסון סטטי — Netlify, Cloudflare Pages,
GitHub Pages, Vercel או שרת Nginx/Apache רגיל. אין תלויות ואין תהליך build.

לפני הפרסום כדאי להוסיף ל-`<head>` שורת canonical עם הדומיין האמיתי:

```html
<link rel="canonical" href="https://הדומיין-שלכם/">
```

השורה לא נוספה מראש כדי לא להמציא כתובת. יש הערת `TODO` במקום המתאים בקובץ.

## איך להחליף תמונה

כל כתובת תמונה בנויה כך:

```
https://res.cloudinary.com/zrevzjvb/image/upload/<טרנספורמציות>/<גרסה>/nagar-alon-pics/<שם הקובץ>.png
```

לדוגמה:

```
.../upload/f_auto,q_auto,c_fill,g_auto,ar_4:5,w_800/v1787857693/nagar-alon-pics/pic_alon_1.png
```

* `f_auto` — פורמט אוטומטי (AVIF/WebP לפי הדפדפן). **לא למחוק.**
* `q_auto` — דחיסה אוטומטית. **לא למחוק.**
* `c_fill,g_auto` — חיתוך חכם שממורכז על נושא התמונה.
* `ar_4:5` — יחס גובה-רוחב (גלריה 4:5, hero 3:2).
* `w_400` / `w_600` / `w_800` — הרוחבים שמופיעים ב-`srcset`.
* `v1787857693` — מספר גרסת הנכס ב-Cloudinary.

להחלפת תמונה: להעלות קובץ חדש לתיקייה `nagar-alon-pics`, ואז להחליף בקוד רק את
**שם הקובץ ואת מספר הגרסה** — ולהשאיר את הטרנספורמציות כפי שהן. חשוב לעדכן את כל
הופעות אותה תמונה באלמנט (`src` ו-`srcset`), ואת ה-`alt` לתיאור מה שנראה בתמונה החדשה.

אם התמונה החדשה אינה ביחס 4:5 או 3:2, ה-`c_fill,g_auto` יחתוך אותה לפי היחס
המבוקש — לכן כדאי לבדוק שהחיתוך לא פוגע ברהיט.

## איך לחבר את הטופס

הטופס בנוי במלואו אבל **אינו מחובר**: אין `action`, אין `method`, כפתור השליחה
`disabled`, ואין הודעת הצלחה מדומה. יש הערת `TODO` מעל ה-`<form>` ב-`index.html`.

לאחר שיהיה endpoint אמיתי בצד שרת:

1. להוסיף ל-`<form>` את `action="https://.../endpoint"` ואת `method="post"`.
2. להסיר את המילה `disabled` מכפתור השליחה.
3. להסיר או להחליף את פסקת המצב `#form-status` ("הטופס המקוון יחובר לפני העלייה לאוויר...").
4. לוודא שהשרת מבצע ולידציה, הגנה מפני ספאם והגבלת קצב, ושהוא מחזיר דף או הודעת
   הצלחה אמיתית — רק אחרי שהפנייה אכן נשמרה או נשלחה.
5. לעדכן את מדיניות הפרטיות ב-`index.html` (סעיף `#privacy`): מי מקבל את הפרטים,
   היכן הם נשמרים ולכמה זמן.

עד אז, ערוצי הקשר הפעילים באתר הם טלפון, WhatsApp ודוא״ל.

### מקור התמונות

בתיקייה `nagar-alon-pics` ב-Cloudinary נמצאו 14 נכסים: לוגו אחד בארבע גרסאות
(`logo1`–`logo4`) ועשר תמונות פנים (`pic_alon_1`–`pic_alon_10`, כולן 1122×1402).
**לאף אחת מהן אין tags, context או מטא-דאטה מסוג EXIF/XMP**, ולכן לא ניתן לאמת
טכנית אילו תמונות נוצרו באמצעות AI ואילו הן צילומים.

בהתאם להנחיה, האתר מציג ליד התמונות את הגילוי המלא ("הדמיה... נוצרה באמצעות AI...").
אם יתברר שחלק מהתמונות הן צילומים אמיתיים של עבודות שבוצעו — יש להסיר מהן את
הגילוי, שכן סימון צילום אמיתי כהדמיה מטעה בדיוק כמו ההפך.

### הערה על הלוגו

הקובץ `logo1.png` (1672×941) מכיל שוליים שקופים רחבים: הסמל והכיתוב תופסים רק
כ-79% מהרוחב וכ-28% מהגובה. הלוגו מוצג באתר במלואו, ללא חיתוך וללא מתיחה, ולכן
הוא נראה קטן יחסית לשטח שהוא תופס בכותרת. כדי לקבל לוגו גדול וחד יותר בכותרת
מומלץ להפיק קובץ לוגו חתוך לשוליים (או להפעיל `c_trim` בחשבון Cloudinary — כרגע
הטרנספורמציה הזו מוחזרת עם שגיאה 400 בחשבון הנוכחי).

## נגישות וביצועים

* `lang="he"`, `dir="rtl"`, פריסה מבוססת logical properties.
* קישור דילוג לתוכן, מבנה כותרות תקין (h1 יחיד), landmarks סמנטיים.
* `<label>` אמיתי לכל שדה, `aria-describedby` לטקסטי עזר, מצבי focus ברורים.
* כל התמונות עם `alt` בעברית, `width`/`height` מפורשים ו-`decoding="async"`.
* תמונת ה-hero נטענת ב-`fetchpriority="high"` וללא `loading="lazy"`; כל היתר `lazy`.
* `srcset` + `sizes` לכל תמונה משמעותית, ו-`f_auto,q_auto` בכל כתובת Cloudinary.
* `prefers-reduced-motion` מבטל גלילה חלקה ומעברים.
* ללא פונטים חיצוניים, ללא trackers, ללא cookies.
